# Study Sprint

A small, three-step study planner that helps turn one overwhelming task into a focused work session.

## Live site

Add your GitHub Pages link here after publishing. If your GitHub username is `shashwatshukla3291` and the repository is named `study-sprint`, the URL will be:

`https://shashwatshukla3291.github.io/study-sprint/`

## What it does

- Guides you through three full-screen steps: choose a task, pick a sprint length, and start a timer
- Offers 15, 25, and 40 minute focus sessions
- Includes a working pause, resume, and reset timer
- Runs in the browser without an account or backend

## Built with

HTML, CSS, and JavaScript.

## Note

The timer is a simple focus aid. Keep this page open while a sprint is running.
